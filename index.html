Núcleo principal de la especificación x402 para eCash. Proporciona la lógica de autorización básica, gestión de facturas, esquemas y firmas criptográficas.

x402-xec-axios

Interceptor y cliente para Axios que automatiza el flujo de L402, permitiendo a las aplicaciones frontend realizar solicitudes HTTP monetizadas sin esfuerzo.

Ver en npm

x402-xec-express

Middleware para servidores Express (Node.js) que intercepta solicitudes, exige pagos L402 mediante eCash y protege rutas de API de forma nativa.

Ver en npm

x402-xec-facilitator

Servicios para emitir facturas (Payment Requests), verificar firmas y confirmar el pago on-chain vía Chronik para validar tokens de acceso x402.

Orquestador en vivo para gestionar transacciones L402. Se integra con adaptadores de wallets de navegador para preparar y firmar políticas de pago en eCash.
